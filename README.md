You describe what you want. AI agents plan it. You approve. They build it. QA validates. PR lands.

```
You → idea → CEO agent plans → YOU APPROVE → Dev agent builds → QA validates → PR ready
```

One command to start: `osai idea "Add dark mode to settings"`
One command to approve: `osai approve 42`

### What's different

- The orchestrator has zero LLM code. Deterministic state machine, not probabilistic guessing.
- Human approval gates. Nothing gets built until you say so.
- Works with any LLM (OpenClaw, Claude, Grok) and any tracker (Jira, GitHub, Forgejo).
- 5 npm dependencies. That's the whole dependency tree.
- Free forever. FSL transitioning to MIT. No feature gates, no licensing surprises.

### The numbers

11 states, 18 transitions, 67 CLI commands, 29+ API routes, 3 agent roles, 21 database tables, 5 dependencies.
